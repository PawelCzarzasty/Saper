# Minesweeper (SFML) 

A classic Minesweeper game implementation written in C++ using the **SFML** library for graphics.

---

##  Project Overview
This project features a fully functional Minesweeper engine and a graphical interface. The goal is to clear the board by uncovering all non-mine cells while avoiding the hidden bombs.

##  Key Features
* **Game Logic:** Robust board management, mine placement, and bomb proximity calculation.
* **Graphics:** Real-time rendering using SFML components.
* **Interaction:** Detection of user inputs to uncover cells or place flags.

##  Tech Stack
* **Language:** C++
* **Library:** SFML (Simple and Fast Multimedia Library)
* **Assets:** Custom textures used for game board elements.

##  How to Run
1. Ensure you have the **SFML library** installed and configured in your IDE.
2. Compile the source files (`mainSFML.cpp` and `MinesweeperBoard.cpp`).
3. Link the necessary SFML modules (`sfml-graphics`, `sfml-window`, `sfml-system`).
4. Run the executable.
